# Changelog

## 1.0.0 - first public release (qualification pending)

- Introduce native boosting and bagging candidate exploration, one-parent selection and a typed depthwise structural mutation, with validation-based acceptance/rollback, finite stopping and optional final numerical Optuna tuning.
- Provide the same evolutionary `fit()` entrypoint for binary, multiclass and regression; prediction, persistence, algorithm inspection and inference export.
- Include curated research history with all **210 original registry entries** indexed, alongside negative outcomes and evidence-level cautions.
- Package a manual Windows CPython 3.12 zero-fit CI workflow; hosted verification and final release approval remain outstanding.

This is the intended **first** official release. Older versions in the archived development history are experimental checkpoints, not past public releases.
