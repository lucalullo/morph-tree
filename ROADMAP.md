# MorphTree roadmap

## First release: 1.0.0

- A complete evolutionary fit interface for binary, multiclass and regression.
- Native parent selection, diagnosis, executable structural mutation, acceptance/rollback, freeze and optional final numerical tuning.
- Model inspection, safe persistence, inference export, bounded resources and verifiable research history.
- Complete the first-commit CI gate and owner release review before publication.

## After 1.0.0

- Broaden the qualified native-family portfolio and add genuinely distinct structural mutation operators.
- Demonstrate beneficial accepted-child continuation on independent data; compare adaptive value against static/tuned controls.
- Improve training speed, memory limits, inference cost and cross-platform support.
- Keep positive, negative and inconclusive results equally accessible.

The roadmap is not a feature list of already-shipped capabilities.
